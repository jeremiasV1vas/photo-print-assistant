# Photo Print Assistant

## Español

**Photo Print Assistant** es un programa de escritorio para Windows 10/11 diseñado específicamente para facilitar la tarea de preparar e imprimir fotografías. 

**¿Para quién es?**
Fue creado para personas con poco manejo de computadoras (específicamente pensado para mi mamá, que tiene una librería y ofrece el servicio de impresión de fotos). 

**¿Por qué existe?**
Los clientes suelen enviar fotos por WhatsApp pidiendo distintos tamaños, y acomodar varias fotos de distintos tamaños en una o varias hojas para imprimir suele ser un proceso manual tedioso en herramientas como Word. Esta aplicación busca automatizar y simplificar este proceso utilizando una interfaz muy amigable y el poder de la IA generativa para sugerir recortes y la mejor distribución en el papel.

**Estado actual**
En diseño / etapa inicial.

## English

**Photo Print Assistant** is a desktop application for Windows 10/11 specifically designed to make preparing and printing photos easier.

**Who is it for?**
It was created for people with limited computer skills (specifically designed for my mom, who runs a stationery store and offers a photo printing service).

**Why does it exist?**
Customers often send photos via WhatsApp requesting different sizes, and arranging multiple photos of different sizes on one or more sheets for printing is usually a tedious manual process using tools like Word. This application aims to automate and simplify this process using a very user-friendly interface and the power of generative AI to suggest cropping and the best layout on the paper.

**Current Status**
In design / initial stage.
